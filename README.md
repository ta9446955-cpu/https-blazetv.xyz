# BlazeTv Kodi Repository

Official Kodi repository for **BlazeTv** - a simple addon for playing your own M3U playlists and your downloaded movies.

## Installation

### Option 1: Install Repository (Recommended)

This allows automatic updates for the addon.

1. **Download** the repository zip using the link above
2. **Go to**: Kodi > Settings > Add-ons > Install from zip file
3. **Select** the downloaded `repository.blazetv.zip`
4. **Restart** Kodi
5. **Go to**: Settings > Add-ons > Install from repository > BlazeTv Repository > Video Add-ons > BlazeTv
6. **Click** Install

### Option 2: Install Addon Directly

If you prefer not to use the repository:

1. **Download** the addon zip using the link above
2. **Go to**: Kodi > Settings > Add-ons > Install from zip file
3. **Select** the downloaded `plugin.video.blazetv-1.0.18.zip`
4. **Restart** Kodi

## After Installation

### Watch live channels from an M3U playlist

1. Open the **BlazeTv** addon
2. Set your M3U playlist one of two ways:
   - **Load M3U from Downloads** - on the main menu, this scans your device's Downloads folder and lets you pick your .m3u/.m3u8 file from a list. No typing required.
   - **Manual entry** - open the addon's **Settings**, then paste your M3U link into the M3U Playlist URL field.
3. Click **Live Channels** and start watching!

(Xtream Codes login is also available in Settings as an optional alternative, but isn't needed if you're using a direct M3U link.)

### Watch your downloaded movies

1. Open the **BlazeTv** addon
2. Click **My Downloads (Movies)**
3. Pick a folder if more than one is shown, then tap a movie to play it

**Movies in a different folder?** Go to **Settings > Features** and type the full folder path in **Movies folder**. Leave it blank to auto-detect.

**Nothing shows on Android?** Give Kodi storage permission in your device's app settings, then try again.

Supported video types: mp4, mkv, avi, mov, m4v, ts, webm, wmv, mpg, mpeg, flv.

## Troubleshooting

### Settings screen looks old or is missing fields
- Uninstall BlazeTv completely, fully close Kodi, then install the latest zip again

### Repository won't install
- Check your internet connection
- Ensure "Unknown sources" is enabled
- Try manual addon installation instead

### Addon won't appear after repository install
- Restart Kodi completely
- Check if the addon shows in Settings > Add-ons > Video add-ons
- Try reinstalling the repository

### My Downloads (Movies) is empty
- Check the movies are in a supported format (see the list above)
- Set the **Movies folder** in Settings > Features
- On Android, make sure Kodi has storage permission
